Dynamic product fetching using REST API.

Category-based product browsing.

Product search by name, description and price.

Price-based filtering.

Individual product details.

Shopping cart functionality.

🛠️ Technologies

React.js | JavaScript | HTML5 | CSS3 | React Hooks | React Router DOM | REST API
